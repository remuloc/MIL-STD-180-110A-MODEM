# INTERLEAVER

## 1. Technical Reference

This implementation uses the article **"A Software Implementation for Federal Standard 1052"** as a technical reference.

The reference describes an 8-PSK modem operating at 2,400 baud.

For the short interleaver configuration, the following matrix dimensions are established:

- Number of rows: 40
- Number of columns: 72
- Total coded bits: 2,880

## 2. FEC–Interleaver Interface

The interleaver receives its input directly from the output of the FEC encoder.

The processing chain is:

```text
FEC Input
   |
   | 1,440 bits
   v
FEC Encoder
   |
   | Coding rate: 1/2
   v
FEC Output
   |
   | 2,880 bits
   v
Interleaver Input
   |
   v
Interleaver
```

The FEC encoder and interleaver must operate on the same binary sequence without independent input generation or manual modification.

## 3. Interleaver Parameters

| Parameter | Value |
|---|---:|
| FEC input | 1,440 bits |
| Coding rate | 1/2 |
| FEC output | 2,880 bits |
| Matrix rows | 40 |
| Matrix columns | 72 |
| Matrix capacity | 2,880 bits |
| Loading step | +9 modulo 40 |

## 4. Matrix Organization

The interleaver uses a 40 × 72 matrix.

\[
40 \times 72 = 2880
\]

Each row contains 72 bits.

The loading sequence uses the following modular operation:

\[
r_{n+1}=(r_n+9)\bmod 40
\]

The exact matrix traversal and readout procedure must follow the technical reference.

## 5. Implementation Objective

The objective is to implement a reproducible interleaver that accepts the actual binary output generated by the project's FEC encoder.

The interleaver must preserve the total number of coded bits:

\[
N_{\text{input}}=N_{\text{output}}=2880
\]

No additional input sequence should be independently generated for the interleaver.

## 6. Validation

The implementation must verify:

- FEC output contains the expected number of bits.
- Interleaver input matches the FEC output exactly.
- The interleaver preserves the total bit count.
- The output contains the same bits as the input, with only their positions rearranged.
